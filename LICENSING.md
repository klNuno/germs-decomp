# Licensing

This repository holds files of very different origins, and they are not all under the same terms. Only the files listed under [MIT licence](#files-under-the-mit-licence) are licensed by this project. Nothing else here is licensed by it: the reconstructed game code, the game's names, data and images, and Sony's SDK interfaces belong to their own rights holders, and this project grants no rights in them.

There is no top-level `LICENSE` file on purpose: such a file would read as a licence for the whole repository, which it cannot be.

## Files under the MIT licence

These files are klNuno's own work, written for this project or, for many tools, copied from lsd-decomp (below), and are licensed under the MIT licence below. The Python, shell and Lua tool sources and the two Git hooks carry a comment line that starts `Licence: MIT for klNuno's own code only` and points here. It is not an SPDX tag on purpose: an SPDX tag would claim the whole file, and some of these files hold content the project cannot license (below).

The licence covers only klNuno's own work in these files: the code, its comments and the documentation's prose, the code copied from lsd-decomp included. Some of them also hold content that is not the project's to license, such as addresses, sizes and layout tables of the retail executable, names of the game and of its reconstructed functions and data, quoted game text, and the names of Sony's SDK libraries and functions. That content stays with its rights holders wherever it appears, and the MIT licence grants nothing in it.

Many of the tools began as copies of the tools of [lsd-decomp](https://github.com/klNuno/lsd-decomp): `tools/split_units.py` says so in its header, and `tools/fmatch.py`, `tools/fn_index.py`, `tools/sjis.py`, `tools/psyq/match.py`, `tools/emu/raw2png.py` and most of the others share much of their code with lsd-decomp's tools of the same name. The copies in this repository are klNuno's, the holder named in the notice below, who licenses them here under the same MIT terms, whatever licence lsd-decomp itself carries.

| Path | What it is |
| --- | --- |
| `tools/*.py`, `tools/*.sh`, `tools/emu/*`, `tools/psyq/match.py` | Build, naming, checking and emulator-driving tools |
| `tools/hooks/pre-commit`, `tools/hooks/pre-push` | Git hooks that refuse game data and broken builds |
| `tools/requirements.in`, `tools/requirements.lock`, `tools/versions.env`, `tools/toolchain.sha256` | Pinned versions and checksums of the toolchain |

| `README.md`, `LICENSING.md`, `disks/README.md`, `docs/*.md`, `docs/engine/*.md` | The documentation's own text |

The documentation's own text means the prose, tables and diagrams written for this project. It does not cover what the documentation quotes or shows: the game's text, names and titles quoted in it, the function and data names of the reconstructed code it cites, and every image (see below).

## Files not under the MIT licence

| Path | Why it is not licensed here |
| --- | --- |
| `src/`, `include/game/`, `include/kaj/` | C reconstructed from the retail executable of Germs: Nerawareta Machi. The program it rebuilds is the work of its developer and publisher. This project does not own it and does not license it. |
| `include/psyq/`, `include/gte.h` | Declarations of Sony's PSY-Q SDK functions and GTE macros named as in that SDK. Sony's interfaces are not licensed here. |
| `config/`, `tools/psyq/hits.tsv`, `tools/psyq/libs.tsv`, `tools/split_units.fixups.patch`, `docs/progress/` | Data that describes the retail executable or holds lines of the reconstructed code: addresses, symbols, layouts, the executable's checksum, the Sony library matches and the progress map generated from them. |
| `docs/img/` | Emulator screenshots, frames of the movie on the disc, and spectrograms of the game's sound recorded from the emulator. They show the game and are shown only to illustrate the findings. |
| `include/include_asm.h`, `include/macro.inc`, `include/labels.inc`, `include/gte_macros.inc` | Files generated by splat, under splat's own MIT licence (see [third-party notices](#third-party-notices)). |
| `include/LICENSE-splat.txt` | splat's licence notice, kept as is. |

No game file is part of this repository: no executable, disc image, disc file, sound or dump of the game's text. Building needs your own original disc.
